# SOP — Pre-Publication Checklist

Run `compliance-reviewer` on every public asset before it goes out. Or check
by hand:

- [ ] RERA number present and correct for the project advertised
- [ ] Every price, area, unit count and date traceable to `projects.md`
- [ ] Carpet area labelled as carpet area
- [ ] Price inclusions stated (GST, registration, maintenance)
- [ ] Every render labelled "artist's impression"
- [ ] No AI-generated property image anywhere in the asset
- [ ] No guaranteed return, assured rental, appreciation or buyback claim
- [ ] No approval, metro line, road or school claimed as existing unless it is
- [ ] Availability matches current inventory
- [ ] Contact details and office address correct

A failure here is a legal exposure, not a typo. When unsure, hold it and ask.
